# Santek eInk panel app thing idk

This is a simple script that lets you write images to a Santek 4.2" BWRY NFC eInk display without needing the official app. You can either supply a local image on your filesystem and have it dither/upload the image, or you can run it as an OpenDisplay TCP server and auto upload images received from an OpenDisplay WiFi server. 

Almost all of this (as of the initial upload) was admittedly me messing around with Claude to see what I could get it to do. It seems to work based on my own testing, but use at your own risk. I'm likely going to go through all of this later and rewrite it myself so I can actually learn what's really happening under the hood.
